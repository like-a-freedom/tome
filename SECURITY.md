# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `tome`, please report it privately
through [GitHub Security Advisories](https://github.com/solovey/tome/security/advisories/new)
for this repository. Do not file a public issue.

You can expect an initial response within 7 days. We will work with you to
understand the impact and coordinate a fix and disclosure.

## Supported Versions

Only the latest minor release receives security fixes. Please upgrade before
reporting an issue against an older version.
